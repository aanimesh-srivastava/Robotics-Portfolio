# Self-Balancing Robot

**Embedded Systems | Arduino | MPU6050 | PID Control**

## Overview

This project involves the development of a self-balancing robot using inertial sensing and feedback control. It combines mechanical assembly, embedded programming, sensor integration, and motor actuation to investigate real-time balance control.

## Engineering Work

- **Sensor Integration:** Using an MPU6050 IMU to measure motion and orientation.
- **Embedded Control:** Implementing PID-based control logic on an Arduino.
- **Motor Control:** Using an L298N motor driver to control the drive motors.
- **System Integration:** Combining the mechanical structure, electronics, and control software.

## Hardware & Technologies

- Arduino
- MPU6050 IMU
- L298N motor driver
- DC motors
- PID control
- Embedded C/C++
