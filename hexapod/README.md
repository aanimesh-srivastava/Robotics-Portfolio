## Overview

This project focuses on the design and development of a six-legged robotic platform with 18 degrees of freedom, using three degrees of freedom per leg.

The goal is to integrate mechanical design, leg kinematics, gait generation, and robotic control into a modular hexapod platform.

## Engineering Work

- **Mechanical Design:** CAD modelling of the robot structure and leg assemblies.
- **Inverse Kinematics:** Developing a three-degree-of-freedom inverse kinematics solution for leg positioning.
- **Locomotion:** Exploring walking gaits, including wave gait generation.
- **ROS 2 Integration:** Developing the software workflow for joint commands and robot control.
- **Simulation:** Using Gazebo and RViz to inspect robot geometry and evaluate behaviour.

## Technologies

- ROS 2
- Python and C++
- Gazebo
- RViz2
- Fusion 360
- Inverse kinematics and gait generation
