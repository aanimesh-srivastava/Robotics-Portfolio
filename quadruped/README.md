## Overview

This project focuses on developing a quadruped robotic platform and exploring legged locomotion through robot modelling and simulation.

The work involves preparing the robot model, configuring its joints and physical properties, and investigating learning-based control approaches to improve locomotion and stability.

## Engineering Work

- **Robot Modelling:** Preparing the robot model and its articulation for simulation.
- **Simulation Setup:** Configuring robot joints and investigating physical behaviour in NVIDIA Isaac Sim.
- **Reinforcement Learning:** Exploring learning-based approaches to robotic control.
- **Testing & Iteration:** Evaluating simulated behaviour and refining the model and setup.

## Tools & Technologies

- NVIDIA Isaac Sim
- NVIDIA Isaac Lab
- URDF and USD workflows
- Python
- Reinforcement learning
