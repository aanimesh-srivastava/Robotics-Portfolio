# Autonomous Rover — Navigation & Path Planning

**ROS 2 | Nav2 | SLAM Toolbox | Gazebo | Autonomous Navigation**

## Overview

This project focuses on developing an autonomous rover using ROS 2, with an emphasis on navigation, mapping, localisation, and path planning.

The development workflow uses simulation to inspect robot behaviour and evaluate navigation components before hardware deployment.

## Engineering Work

- **ROS 2 Integration:** Developing a modular robotics software workflow.
- **Navigation:** Working with Nav2 for autonomous navigation.
- **Mapping & Localisation:** Exploring SLAM Toolbox.
- **Path Planning:** Implementing A* path planning.
- **Simulation:** Using Gazebo and RViz to inspect the robot model and navigation behaviour.

## Tools & Technologies

- ROS 2
- Nav2
- SLAM Toolbox
- Gazebo
- RViz2
- Python and C++
