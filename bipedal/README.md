# Bipedal Robot — Modelling & Simulation

**Mechanical Design | Robot Kinematics | Joint Control | NVIDIA Isaac Sim**

## Overview

This project focuses on developing a bipedal robot model and preparing it for simulation. The objective is to investigate robot articulation, joint coordination, and the mechanical factors that influence balance and stability.

## Engineering Work

- **Mechanical Modelling:** Developing the robot geometry and leg configuration.
- **Robot Description:** Working with URDF and USD workflows to prepare the robot for simulation.
- **Articulation:** Configuring joints and examining their movement.
- **Simulation:** Investigating robot dynamics and stability.
- **Iteration:** Identifying modelling and configuration issues and refining the simulation setup.

## Tools & Technologies

- Fusion 360
- URDF and USD
- NVIDIA Isaac Sim
- NVIDIA Isaac Lab
- Python

## Project Files

This folder will contain:

- CAD renders and robot screenshots.
- Engineering drawings.
- Robot model files, where appropriate.
- Simulation recordings.
- Technical notes and development results.

## Current Status

The robot model has been imported into the simulation workflow, and joint behaviour and physical stability are being investigated.

The project remains under development. Simulation performance should not be interpreted as proof of successful physical locomotion.
